# 30-Day Linux Command Mastery Challenge

This repository is my public build log for the IOTB TECH 30-Day Linux Command Mastery Challenge — 300 commands, 30 days, 6 themed phases, moving from basic filesystem navigation through permissions, users and packages, environment and text processing, process and service management, and finally networking, scripting, and SSH. Every day includes the commands covered, a practice drill run against a real system, and evidence that the drill was actually completed — no copy-pasting, no skipped days. This is part of a broader effort to build hands-on Cloud and DevOps Engineering skills alongside my existing background in mechanical/energy systems engineering.
