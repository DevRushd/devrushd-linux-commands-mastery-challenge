### PRACTICE DRILL

---
**STEPS**
---

- Open a terminal
- print your working directory: `pwd` 
- navigate to /var/log using an absolute path: `cd /var/log`
- back to your home directory using ~: `cd ~`
- finally return to /var/log using cd -: `cd -` 
- List its contents in long, human-readable format: `ls -lh`
